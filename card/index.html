10년 경력의 전문 수학 지도

개념의 원리부터 서술형 · 수리논술 기초까지, 학생의 수준과 목표에 맞춰 수학적 사고의 전 과정을 지도합니다.

개념 이해와 원리 중심

공식 암기에 그치지 않고 수학적 원리와 개념을 정확히 이해해 응용할 수 있도록 지도합니다.

오답 분석과 취약점 보완

정답과 오답을 넘어 틀린 원인을 분석하고, 부족한 개념과 문제 해결 과정을 체계적으로 보완합니다.

다양한 표현을 통한 개념 이해

수직선과 수의 관계, 좌표와 도형, 수식과 그래프 등 다양한 표현을 활용해 하나의 개념을 여러 관점에서 이해하도록 지도합니다.

학생별 수준 맞춤 지도

학생마다 다른 이해도와 학습 속도를 고려해 진도와 학습 방법을 세밀하게 조정합니다.

개념 검증 기반의 서술형 · 수리논술 기초

공식과 개념의 적용 가능성을 먼저 확인하고, 이를 바탕으로 풀이를 설계해 논리적 전개부터 최종 정답 검토까지 지도합니다.

실제 수업은 이렇게 진행됩니다

강사가 다양한 방식으로 개념을 설명하고, 학생도 자신의 이해와 풀이 과정을 직접 설명하며 함께 확인합니다.

01
하나의 개념을 여러 방식으로 이해

표현을 바꾸어 보며 개념의 원리와 관계를 확인합니다.

  1. 수직선과 수의 관계수직선 위에서 수의 크기와 위치, 관계를 확인
  2. 좌표와 도형좌표와 도형으로 개념 사이의 관계를 시각적으로 확인
  3. 수식과 그래프수식과 그래프를 함께 살펴보며 개념을 시각화하고 비교
  4. 문제에 적용이해한 원리를 새로운 문제에 활용
02
개념 검증부터 정답 확인까지, 서술형 · 수리논술 기초

알고 있는 개념을 근거로 풀이를 설계하고 결과까지 점검합니다.

  1. 개념 검증사용할 공식과 개념을 정확히 이해하고 있는지 확인
  2. 풀이 설계검증한 개념을 바탕으로 해결 전략과 순서 구성
  3. 논리적 전개수학적 근거를 제시하며 풀이 과정을 작성
  4. 결과 검토논리와 계산을 점검하고 최종 정답까지 확인
